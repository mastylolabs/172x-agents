# Security Policy

## Reporting a vulnerability

Please do **not** report suspected vulnerabilities through public GitHub issues, pull requests, or
discussions.

Email [zbigniew@mastylolabs.com](mailto:zbigniew@mastylolabs.com) with:

- a concise description of the issue and affected versions or files;
- reproducible steps or a minimal proof of concept, where safe to share;
- the potential impact; and
- any suggested mitigation.

Mastylo Labs LLC will acknowledge the report, investigate it privately, and coordinate an
appropriate fix and disclosure. Please give maintainers a reasonable opportunity to resolve the
issue before sharing details publicly.

## Scope

This policy covers the source code and released artifacts of this repository. Do not include
credentials, production data, or other sensitive third-party material in a report.
