# Threat modeling

For material trust-boundary changes, identify assets, actors, entry points, trust boundaries, and plausible abuse paths.

- Check authentication, authorization, input validation, secrets, logging exposure, dependency risk, and unsafe defaults.
- Prioritize concrete exploitability and impact over generic hardening advice.
- Distinguish confirmed vulnerabilities from risks that need more evidence.
- State mitigations, ownership, and residual risk without claiming a security guarantee.
